# Sang Kancil Specialist Clinic staff assistant

A staff assistant for a fictional private paediatric clinic in Kota Damansara, Selangor: three paediatricians and one clerk manage cases between them. The AI only chooses which of eight tools to call; one PreToolUse hook, one PostToolUse hook and the back end apply the clinic's access rule and its clinical and billing checks in code.

Build and test: see CLAUDE.md. Demo data, prices and the formulary are fictional and not for clinical use.
