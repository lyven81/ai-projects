# Service Area

Pak Razif Garden (fictional demo business). Cite clauses by ID, e.g. A1.

Where a site visit can be booked instantly. The check uses the postcode; the assistant asks for it if the customer has not given it.

## 1. Approved coverage

- **A1** Area: Shah Alam. Postcodes: 40000 to 40470. Includes: All sections, Setia Alam, Bukit Jelutong, Kota Kemuning, Alam Impian.
- **A2** Area: Klang. Postcodes: 41000 to 41300. Includes: Klang town, Bandar Botanic, Bukit Tinggi, Bukit Raja.
- **A3** Area: Subang Jaya. Postcodes: 47500, 47600 to 47650. Includes: Subang Jaya, USJ.

## 2. Outside the coverage

- **A4** Any other postcode, including nearby areas, is forwarded to Pak Razif with the location and job details for his approval (R5). No visit is booked and acceptance is not promised. *(Enforced by: Code (booking tool checks the postcode))*
- **A5** Outstation jobs, such as Melaka, Penang or Johor, are forwarded for assessment without promising acceptance. *(Enforced by: Code (handover reason))*
- **A6** If the postcode is missing or unclear after asking once, the enquiry is forwarded. *(Enforced by: Prompt)*

Demo data: the business is fictional. The postcode ranges were drafted for the demo and should be checked before real use.
