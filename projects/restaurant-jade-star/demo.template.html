Live chat calls the Anthropic API from this page with your key, so every message is billed to your Anthropic account (Claude Haiku 5.5, roughly USD 0.002 to 0.005 a message). Use a key with a low spending limit and delete it when you are done. The key is kept only in this page's memory and is sent only to api.anthropic.com. A public service would keep the key on its own server instead.
