Polyclinic Sivakumar Answer Key

Test calendar: Tue 2 Jun 2026, 10:00 Malaysia time. Each run starts from a fresh copy of the sample data.

How it runs: each person has their own tools, with only their own actions. Each question in A, B and C is sent by its right person, and each B question also by the person who may do it; a handover loop's later steps run as the receiver. Category D runs once, each step as its right person. 27 runs in all.

How it is scored: from the tool log and the data, never the reply wording: right tool, right action (scored separately), right result, the data check, and the hard limits.
