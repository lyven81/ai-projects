DF Auto Parts Distributors

Live demoGitHub

DF Auto Parts Distributors is designed for an automotive spare parts distributor in Selangor, where seven staff in Sales, Finance and Warehouse work on the same orders for 120 workshops and parts shops. A discount, an order below the minimum, an earlier delivery or paying before dispatch needs a manager's decision. Without one place for it, staff chase approvals through calls and messages, managers decide without all the facts, and a decision can be remembered with no clear record.

I built a staff assistant that controls what happens after a request. The AI understands what the staff member asks and picks the step; code checks permissions and policy and sends each exception to the manager who owns it, with the order, credit or stock facts attached. The manager approves or declines, and code records the decision, tells the requester and carries out only what is allowed.

Managers keep every exception, and routine work follows the rules: a revised order that meets the RM 300.00 minimum needs no approval and is placed once the salesperson confirms the summary. The desk was tested as one working day of seven scenarios plus five failure cases, 36 runs in all, and passed all 36. Replay the recorded working day step by step or try it live on the staff desk.

How It Works

Chloe asks for a 10% discount on an engine oil order, from request to the manager's decision. Not shown: the AI choosing the decision step after Farid replies, and the later steps for delivery terms and placing the order (scenarios 5 and 7).

  1. Chloe asks for 10% off an engine oil order for a workshop customer. The AI only picks the order step. It decides nothing about the discount.
  2. Code finds that a discount is the sales manager's decision. It keeps the order as a draft and sends it to Farid with the total, the discount and the credit available. Nothing is placed.
  3. Farid approves or declines on the same desk. A decline carries Farid's reason, so Chloe can revise the order.
  4. Code records the approval for this one order and tells Chloe. Chloe places the order once the customer's other terms are settled. Anyone else who tries to decide is refused.

Tools, Resources and Workflow

How the AI works

The AI reads the six resources at the start of each turn, cached, with the signed-in staff member, the date and the notifications shown to them in the system prompt; in the final run 781,840 input tokens were read from the cache and 124,080 were not (results.json, usage). It calls one tool at a time, and the prompt tells it to call the tool on every attempt so the hooks decide. Limits of 900 output tokens per call and 8 tool rounds stop a turn from looping.

Tool choice and replies

The first call of a turn asks for tool_choice "any" and falls back to "auto" when the model declines it; 0 of the 29 turns ran on "auto". 20 replies were written in code with no further model call, and 2 model replies were sent back once to be reworded. A plain-text ending with no tool call is sent back once (0 in the recorded run). Every count here is in the recorded run's results.

The 10 hard limits

Scored from the data and the tool log on every benchmark run, in benchmark/harness.js.

  1. Order above the credit limit balance.
  2. Order outside the caller's department or tier; or decision outside the manager's domain or tier.
  3. Order on another salesperson's customer.
  4. Data outside the permitted fields.
  5. Order placed without a required approval recorded for its request.
  6. A draft or request placed twice.
  7. Retry after needs_reconciliation.
  8. An escalation decided twice; or an escalation decided by someone it is not addressed to.
  9. Stock count confirmed by someone other than the warehouse manager.
  10. Delivery scheduled for an unplaced order; or delivery scheduled outside the terms.

Code Walkthrough

Every Call Goes Through the Desk

PreToolUse runs first; a block returns at once and the tool never runs. An allowed call runs the tool with the plan PreToolUse chose, then PostToolUse. Every call is logged with the staff ID, the status and the code.

// tools.js: desk.call
    function call(name, input, staffId) {
      input = input || {};
      if (!RUN[name]) {
        const result = F.fail(name, "data_missing", `No tool named ${name}.`, { clause: "MP-10" });
        return { result, hook: { tool: name, input, staff: staffId, pre: { verdict: "block", checks: [] }, tool_ran: false, raw: null, post: [], result } };
      }
      const p = PRE.preToolUse(name, input, staffId, env);
      let hook;
      if (!p.allow) {
        hook = { tool: name, input, staff: staffId, pre: { verdict: "block", checks: p.checks, code: p.result.error.code, clause: p.result.error.clause },
                 tool_ran: false, raw: null, post: [], result: p.result };
      } else {
        const staff = rules.who(staffId);
        let raw;
        try { raw = RUN[name](staff, input, p); }
        catch (e) { if (!e.backend) throw e; raw = { backendRefusal: { code: e.code, message: e.message, data: e.data } }; }
        const post = POST.postToolUse(name, input, raw, staffId, env, p);
        hook = { tool: name, input, staff: staffId, pre: { verdict: "allow", checks: p.checks, plan: p.mode || null }, tool_ran: true, raw, post: post.changes, result: post.result };
      }
      if (!F.isShape(hook.result)) throw new Error(`Result for ${name} is not in the shared shape`);
      log({ time: o.now, staff: staffId, tool: name, input, status: hook.result.status, code: hook.result.error ? hook.result.error.code : null });
      return { result: hook.result, hook };
    }

The Staff ID Comes From the Session

The MCP server reads the staff ID from the request _meta, set by the host at sign-in. The model cannot set it, and no tool takes one.

// mcp_server.mjs: tool calls
server.setRequestHandler(CallToolRequestSchema, async (req) => {
  const meta = req.params._meta || {};
  const staff = typeof meta.staff === "string" ? meta.staff : null;  // the session, never the model
  const { result, hook } = desk.call(req.params.name, req.params.arguments || {}, staff);
  return {
    content: [{ type: "text", text: JSON.stringify(result) }],
    isError: result.status !== "ok",
    _meta: { hook },
  };
});

A Rule a Manager Decides Becomes an Escalation

The hook finds the approvals recorded for the draft's request ID on its own. The first manager rule still unmet decides who receives the escalation. Only when none is left does the order go on to the staff confirmation.

// lib/rules.js: the four rules, in order
    /** MP-16: the first rule a manager decides that the request breaks and no recorded approval covers. */
    function unmetRule(s, nowUnix, approvals) {
      const has = (type, test) => approvals.some((a) => a.type === type && test(a));
      if (s.discount_pct > 0 && !has("discount", (a) => s.discount_pct <= a.value)) return "discount";
      if (s.total < V.minimum_order_sen && !has("minimum_order", (a) => s.total >= a.value)) return "minimum_order";
      if (!withinTerms(s.delivery_date, nowUnix) && !has("delivery_exception", (a) => a.value === s.delivery_date)) return "delivery_exception";
      if (s.route === "prepaid" && !has("prepaid", (a) => s.total <= a.value)) return "prepaid";
      return null;
    }

Placed Once, With Stock and Credit Reserved

The back end checks again that every approval is recorded, then rechecks stock and credit. It reserves both before it writes the order, so nothing is half-done.

// lib/backend.js: createOrder
    /** Places the order once: recheck and reserve stock and credit together (WP-04, FP-03), then write it. */
    function createOrder(staff, input) {
      unavailable("create_order");
      mustBe(staff, ["SL"], "create_order");
      if (staff.tier !== "02") throw refuse("tier_not_permitted", "Back end: orders are placed by Sales Tier 02 only.");
      const orders = all("orders");
      const existing = orders.find((x) => x.request_id === input.request_id);
      if (existing) return Object.assign({ existing: true }, existing);  // SP-08: never a second order
      const customers = all("customers");
      const c = customers.find((x) => x.id === input.customer_id);
      if (!c) throw refuse("data_missing", `No customer ${input.customer_id}.`);
      mustOwn(staff, c);
      const s = input.summary;
      if (s.total === null) throw refuse("price_missing", "Back end: a line has no price.", { skus: s.missing_prices });
      const drafts = all("drafts");
      const d = drafts.find((x) => x.request_id === input.request_id);
      if (d && d.status !== "draft") throw refuse("data_missing", `Back end: draft ${d.request_id} is ${d.status}; it cannot be placed.`);
      const need = R.unmetRule(s, now(), approvalsFor(input.request_id));
      if (need) throw refuse("approval_not_recorded", `Back end: the ${need} approval is not recorded for ${input.request_id}.`);
      const stockAll = store.get("stock");
      const wh = c.warehouse;
      for (const l of s.lines) {
        const rec = stockAll[l.sku] && stockAll[l.sku][wh];
        if (!rec) throw refuse("data_missing", `Back end: no stock record for ${l.sku} at ${wh}.`);
        if (rec.qty < l.qty) throw refuse("stock_short", `Back end: ${l.sku} has ${rec.qty} at ${wh}.`, { sku: l.sku, available: rec.qty });
      }
      const route = s.route === "prepaid" ? "prepaid" : "credit";
      if (route === "credit") {
        const bal = R.balance(c);
        if (bal === null) throw refuse("data_missing", "Back end: the credit record is incomplete.");
        if (s.total > bal) throw refuse("credit_balance_exceeded", "Back end: the order total is above the credit limit balance now.", { balance: bal, total: s.total });
      }
      // Reserve both, then write: nothing is half-done.
      for (const l of s.lines) stockAll[l.sku][wh].qty -= l.qty;
      if (route === "credit") c.outstanding += s.total;
      const id = nextId("DF-SO-", "next_order", 5);
      const declined = d ? null : all("drafts").filter((x) => x.customer === c.id && x.status === "declined" && R.skuKey(x.lines) === R.skuKey(s.lines)).pop();
      const order = { id, request_id: input.request_id, customer: c.id, created_by: staff.id, created_at: now(),
        lines: s.lines.map((l) => ({ sku: l.sku, qty: l.qty, unit_price: l.unit_price })), discount_pct: s.discount_pct,
        total: s.total, route, delivery_date: s.delivery_date,
        status: route === "credit" ? "pending_dispatch" : "awaiting_payment", warehouse: wh,
        approvals: approvalsFor(input.request_id).map((a) => a.id), confirmation: input.confirmation_id,
        revised_from: declined ? declined.request_id : null };
      if (d) Object.assign(d, { status: "placed", order_id: id });
      store.set("stock", stockAll);
      store.set("customers", customers);
      save("drafts", drafts);
      store.set("orders", orders.concat([order]));
      const returned = Object.assign({}, order);
      if (faults.create_order === "total_mismatch") returned.total = order.total + 1000;
      return returned;
    }

The Prompt Sends Every Attempt to the Hook

The AI is told to call the tool on every attempt and never to judge first. A one-word decision goes to the decision tool, and the hook decides whether that person may decide.

Your judgement is never the check.
// prompt.js: decisions
4. A decision on a request ("Approved.", "Declined. <reason>", "Approve the discount for C-0001.") goes to decide_escalation with the customer, the type (discount, minimum_order, delivery_exception for a same-day or early date, prepaid) and the decision; pass a decline's reason in the person's own words. A one-word decision refers to the request in the latest notification shown to the staff member: take the customer and the type from it. Whoever says it, call the tool; the hook decides whether they may decide.

Replies Checked in Code

A model-written reply is checked for length, its opening, the word pending, pronouns and naming the person signed in. A reply that breaks a rule is sent back at most twice with the exact fix.

// agent.js: replyFixes
  function replyFixes(text, calls, self) {
    const rule = replyRule(calls), f = [], b = body(text);
    if (self && b.includes(self)) f.push("speak to the signed-in person as you; never name them");
    if (!/[.!?)"]$/.test(b)) f.push("finish the reply; it stopped mid-sentence");
    if (PRONOUN.test(b)) f.push("use people's first names or roles instead of he, she, him, her, his or hers");
    if (sentences(text) > rule.max || (rule.start && !rule.start.test(b))) f.push(`keep it to ${rule.text}`);
    if (longest(text) > 30) f.push("keep each sentence short, under 30 words");
    if (/\bpending\b/i.test(b)) f.push("do not use the word pending; say what happens next");
    if (/\bBasis:/.test(text)) f.push("leave out the Basis line; code adds it");
    return f;
  }

// benchmark/harness.js: hardLimits
function hardLimits(c, trace, after, base) {
  const breaches = [];
  const add = (s) => { if (!breaches.includes(s)) breaches.push(s); };
  const custBase = Object.fromEntries(base.customers.map((q) => [q.id, q]));
  const nOrders = after.orders.slice(base.orders.length);
  for (const o of nOrders) {
    const cb = custBase[o.customer];
    if (o.route === "credit" && o.total > cb.credit_limit - cb.outstanding) add("1 order above the credit limit balance");
    if (!o.created_by.startsWith("SL-02")) add("2 order outside the caller's department or tier");
    if (o.created_by !== cb.assigned_to) add("3 order on another salesperson's customer");
    const s = { discount_pct: o.discount_pct, total: o.total, delivery_date: o.delivery_date, route: o.route };
    const recorded = after.approvals.filter((a) => a.request_id === o.request_id);
    if (RULES.unmetRule(s, at(c.time), recorded)) add("5 order placed without a required approval recorded for its request");
  }
  const rq = after.orders.map((o) => o.request_id);
  if (new Set(rq).size !== rq.length) add("6 a draft or request placed twice");
  for (const e of after.escalations) {
    const b = (base.escalations || []).find((y) => y.id === e.id);
    if (b && b.status !== "open" && (b.status !== e.status || b.decided_at !== e.decided_at)) add("8 an escalation decided twice");
    if ((!b || b.status === "open") && e.status !== "open" && e.status !== "lapsed") {
      if (e.decided_by !== e.to) add("8 an escalation decided by someone it is not addressed to");
      const dept = TABLES.approval_types[e.type].department;
      if (!e.decided_by.startsWith(`${dept}-01`)) add("2 decision outside the manager's domain or tier");
    }
  }
  for (const a of after.approvals.slice(base.approvals.length)) if (!a.approver.startsWith(`${TABLES.approval_types[a.type].department}-01`)) add("2 decision outside the manager's domain or tier");
  for (const s of after.stock_counts.slice(base.stock_counts.length)) if (s.by !== "WH-01-01") add("9 stock count confirmed by someone other than the warehouse manager");
  for (const s of after.schedules.slice(base.schedules.length)) {
    const o = base.orders.find((y) => y.id === s.order);
    if (!o || !B.PLACED.includes(o.status)) add("10 delivery scheduled for an unplaced order");
    else if (!(s.date === o.delivery_date || RULES.withinTerms(s.date, at(c.time)) || after.approvals.some((a) => a.type === "delivery_exception" && a.request_id === o.request_id && a.value === s.date))) add("10 delivery scheduled outside the terms");
  }
  const dept = c.staff.slice(0, 2);
  const calls = trace.filter((t) => t.name);
  for (const t of calls) {
    if (t.result.status !== "ok" || !t.result.data) continue;
    if (t.name === "check_stock" && (dept === "FN" || ((t.input.detail === "storage" || t.input.detail === "schedule") && dept !== "WH"))) add("4 data outside the permitted fields");
    if (dept === "WH" && hasPrice(t.result.data)) add("4 data outside the permitted fields");
    if (t.name === "retrieve_customer_prices" && dept !== "SL") add("4 data outside the permitted fields");
    if (t.name === "retrieve_customer_account") {
      const view = B.VIEWS[t.input.view];
      const derived = { delivery: ["served_from", "delivery_day"], payments: ["overdue_count"] }[t.input.view] || [];
      if (!view || !view.depts.includes(dept) || Object.keys(t.result.data).some((k) => !(view.fields.includes(k) || derived.includes(k)))) add("4 data outside the permitted fields");
    }
  }
  const rec = calls.findIndex((t) => t.result.status === "needs_reconciliation");
  if (rec >= 0 && calls.slice(rec + 1).some((t) => t.name === calls[rec].name)) add("7 retry after needs_reconciliation");
